# Local changes review

Review the working-tree changes that the sibling Hunk pane displays.
The display includes staged, unstaged, and untracked changes by default.
Confirm the current repository and diff scope before the review.
Do not assume that the review target is a committed branch comparison.

Read project instructions and inspect the relevant code and tests.
Ask before tests or commands that modify repository files, generated files, or external state.
Report actionable defects first. Explain each defect and identify its file and line.
State what you checked and which tests you did not run.
Do not make fixes unless Zero Cool changes the task from review to implementation.
